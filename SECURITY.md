# Security policy

Please report vulnerabilities privately. Don't open a public issue.

- **Preferred:** [report a vulnerability](https://github.com/OrchestrAIio/orchestrai/security/advisories/new) through GitHub's private reporting.
- **Or by email:** support@orchestrai.io with "Security" in the subject line.

What we cover:
- The code in this repository: the CLI, the ACP bridge and the Claude Code plugin.
- The OrchestrAI editor extension and the OrchestrAI service.

We'll confirm we've received your report within 3 working days and keep you updated until it's fixed. Please give us a reasonable chance to fix the problem before you disclose it publicly.

Please don't test against other people's accounts or data, run denial-of-service tests against the service, or use social engineering.
